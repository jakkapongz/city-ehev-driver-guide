## ที่มาและข้อจำกัด

เนื้อหาย่อมาจาก “สมุดรับประกันและคู่มือผู้ใช้รถ Honda City Hatchback e:HEV”
ซึ่งเป็นเอกสารลิขสิทธิ์ของ Honda จัดทำขึ้นเพื่อใช้อ่านทบทวนอย่างรวดเร็วเท่านั้น
ไม่ใช่เอกสารทางการและไม่มีความเกี่ยวข้องกับ Honda

หน้านี้ตัดรายละเอียดจำนวนมากออกไป เช่น การติดตั้งเบาะนั่งเด็ก ถุงลมนิรภัย
และขั้นตอนเชิงลึกอื่นๆ เมื่อต้องตัดสินใจจริง ให้ยึดตามคู่มือเล่มจริง
และศูนย์บริการฮอนด้าเป็นหลักเสมอ
